# Threads スキンケアアフィリエイト

## なぜやるのか
Threadsは投稿そのものでは収益が出ない（2026年9月時点で日本では収益分配なし）。アフィリエイトで収益化する。
25年のニキビ経験と、妊娠でニキビがゼロになった実体験を活かし、同じ悩みの人に届く発信をする。

## コンセプト
> ニキビ歴25年。皮膚科・ピル・食事制限でも治らなかった肌が、妊娠でゼロに。ホルモンと肌の記録。

- ターゲット: 長年ニキビに悩んできた人 / 生理前など、ホルモンで肌が荒れやすい人
- アフィリエイト専用アカウント（業務効率化のnote・Xとは切り離す）
- 自分の経験を入れる。必要になったら肌の写真も載せるかも
- 軸は過去・現在・未来の3つ
  - 過去: 25年の試行錯誤
  - 現在: 妊娠でニキビがゼロに
  - 未来: 産後の肌の変化をリアルタイムで記録

## 自分の経験（ネタの元）
- 小6から25年、ニキビがない日はなかった
- 試したこと: 皮膚科に通って薬を続けた（完治せず）、低用量ピル、水洗顔、糖質制限、チョコ断ち、スナック断ち
- 妊娠してから、ニキビがひとつもできなくなった
- 使っているもの: メイク落とし＝アテニア

## プロフィール文（確定）
```
ニキビ歴25年｜皮膚科・ピル・食事制限、ぜんぶ試した
妊娠したらニキビがゼロに｜ホルモンと肌の記録
使ってよかったものだけ紹介します
```

## はじめの投稿（確定）
```
小6から25年、ニキビがない日はなかった。
皮膚科に通っても、ピルを飲んでも、糖質もチョコもやめても、治らなかった。

それが妊娠してから、ひとつもできなくなった。

ホルモンって、こんなに肌を左右するんだと実感してる。
ここでは、25年の試行錯誤と、これからの肌の変化を記録していきます。
```

## 投稿ネタのストック
- 皮膚科に◯年通ってわかったこと
- 水洗顔を続けた結果
- 糖質制限・チョコ断ち・スナック断ちで肌は変わった？
- 低用量ピルを飲んでいたときの肌（体験談として。紹介はしない）
- 妊娠してニキビがゼロになった話
- アテニアのメイク落としを使っている理由（アフィリエイト候補）
- （出産後）産後の肌の変化

## 投稿ペース
- 今から始めて、できれば毎日投稿
- 10月に出産予定なので、出産前に投稿のストックを作っておく

## ルール（守ること）
- **PR表記**: アフィリエイトリンクを載せる投稿には「PR」「広告」をつける（ステマ規制・2023年10月〜）
- **薬機法**: 化粧品で「ニキビが治る」「ニキビに効く」「シミが消える」と言い切らない。「私の場合はこうだった」という体験談の形で書く
- 皮膚科の薬・ピルは医療なのでアフィリエイトしない（体験談として話すのはOK）
- 妊娠中・産後の人向けには「私が使っているもの」の紹介にとどめる

## ASP（アフィリエイトサービス）
- 候補: もしもアフィリエイト（Amazon・楽天・Yahoo!をまとめて扱える。化粧品ブランドの案件も多い）
- 手順: Threadsアカウントを作る → ASPに登録（登録時に紹介するSNSを書くため）
