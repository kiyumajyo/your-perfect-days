# 認証基盤移行（Cognito → Auth0）

## なぜやるのか
Cognitoのカスタム認証フローの制約で、ソーシャルログイン追加のたびにLambdaトリガーが肥大化している。Auth0に移行して認証ロジックをシンプルにし、今後のログイン手段追加を楽にする。
