# Perfect Days

**「今日はいい日だったな」で終わる毎日を。**

頭の中の気がかりなことを外に出し、意図通りの一日を過ごすための、Claude Code で動くパーソナルコーチ。

---

**やることに追われる毎日から、「こう過ごしたい」が叶う毎日へ。**

---

## はじめ方

### 1. Claude Code をインストール

```bash
npm install -g @anthropic-ai/claude-code
```

### 2. このフォルダを好きな場所に置く

例: ホームディレクトリやデスクトップなど、自分が見つけやすい場所に `your-perfect-days` フォルダごと移動する。

### 3. Claude と話す

```bash
cd your-perfect-days
claude
```

初回は Claude が対話を通じて、あなたの全体像を映す `now.md` を作ってくれる。
名前、リズム、プロジェクト、今の気がかりなこと — 全部ここに集約される。

---

## 使い方

毎日 `your-perfect-days` ディレクトリで Claude を起動するだけ。

```bash
cd your-perfect-days
claude
```

Claude は `now.md` を読んで、あなたの今日を把握した状態でスタートする。

### `/session` — 25分セッションで一日を回す

「今日が perfect day になるために、今やるべきこと」を逆算して提案。
25分集中 → 休憩 → 次のセッション、のループで一日を駆動する。

### `/dump` — 頭の中を全部出す

気がかりなことを全部吐き出して、問題と解決策のペアに整理する。
終わったあとの頭のスッキリ感がゴール。

### `/shutdown` — 一日を閉じる

不要なアプリを閉じて、夜ルーティンのチェックリストをブラウザで開く。
明日の準備をして、気持ちよく眠る。

## 構造

```
now.md           — 自分の全体像。Claude はこれだけ読めば全部わかる
days/            — その日の出来事の記録（YYYY-MM-DD.md）
projects/        — 複数日にまたがるプロジェクトの詳細
reflections/     — 週・月・四半期の振り返り
archive/         — 終了したプロジェクト
```

ファイルの作成・更新は全て Claude がやる。あなたは話すだけでいい。
会話の中で出てきたことを Claude が `now.md` に反映し、日々の記録を `days/` に書き、繰り返し出てくるテーマを `projects/` に昇格させる。

---

## 安全設定について

このフォルダには `.claude/settings.json` が同梱されている。Claude Code を初めて使う人でも安心して触れるよう、安全側に倒した初期設定が入っている。

- **ブロックされる**: `.env` や SSH 秘密鍵などの機密ファイル読み取り、`rm -rf /` などのシステム破壊コマンド
- **必ず確認される**: ファイル削除（`rm`）、リモートへのアップロード（`git push`）、外部通信（`curl`、`wget`）、管理者権限実行（`sudo`）
- **ノンストップで動く**: このフォルダ内のファイル読み書き、現在地・ファイル一覧の確認

設定の中身は `.claude/settings.json` を直接見て、自分の使い方に合わせて編集して OK。
